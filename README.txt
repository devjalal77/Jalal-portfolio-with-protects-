RUN LOCALLY
Open index.html in a browser.

PUBLISH WITH GITHUB PAGES
1. Create a public GitHub repository, for example: jalal-uddin-portfolio
2. Upload index.html, style.css, and the assets folder to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and / (root), then Save.
6. After GitHub finishes publishing, your website URL will appear in the Pages section.
